# 科研实训过程记录

本目录是可复制到腾讯共享文档的过程性材料。日期和事件根据 Git 提交、设计文档
与实验清单整理，不代表当时真的召开过同名会议，也不补写老师没有说过的话。

1. `01-选题与研究问题.md`：研究范围和问题。
2. `02-系统设计方案.md`：从 Arrow 到各执行后端的设计。
3. `03-实验设计.md`：正式矩阵、计时和正确性口径。
4. `04-阶段讨论记录.md`：根据仓库记录整理的阶段变化。
5. `05-实验执行日志.md`：实际跑过的正式实验。
6. `06-问题与决策记录.md`：出错、定位和取舍。
7. `07-最终完成情况.md`：完成、排除和外部待办。
8. `TENCENT_DOCS.md`：腾讯文档同步状态。

当前正式证据锚点为 `docs/artifacts/v5_sf1/manifest.sha256`。
