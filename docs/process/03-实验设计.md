# 03 实验设计

**日期范围：** 2026-07-13 至 2026-07-14

## 目标

让每条性能结论都可以从原始运行记录重算，并且失败不会被静默删除。

## 活动与证据

| 项目 | 正式口径 |
| --- | --- |
| 数据 | TPC-H SF1 Arrow，ASIA，起始日期 1994-01-01 |
| 配置 | 19 组：CPU 6、Acero 6、CUDA 3、hybrid 3、cuDF 1 |
| 重复 | 每组 3 次 warmup + 10 次 measured cold process |
| 查询时间 | `query_total_ms`，后端内部查询阶段 |
| 进程时间 | `process_elapsed_ms`，包含启动和装载等外部成本 |
| 统计 | min、median、max、p95、样本标准差 |
| 正确性 | `result_hash` 一致且 `oracle_status=passed` |
| 失败 | 保留 timeout、OOM、no GPU、launch error 等状态 |

完整矩阵在 `experiments/v5_formal_sf1.yml`，统计契约在
`scripts/summarize_run_records.py`，证据审计在 `scripts/evidence_bundle.py`。

## 未解决问题

正式矩阵没有 resident，也没有 NVML GPU 峰值显存和 Nsight 时间线。

## 下一步决定

论文区分查询时间与进程时间；没有 profiler 证据时不写 kernel 级 overlap。
