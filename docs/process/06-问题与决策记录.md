# 06 问题与决策记录

**日期范围：** 2026-07-13 至 2026-07-14

## 目标

记录对最终结果有影响的问题，以及采用和放弃的方案。

## 活动与证据

| 问题 | 决策 | 原因/证据 |
| --- | --- | --- |
| 逐行收入先截断到分 | 改为 `revenue_1e4` 聚合后舍入 | 旧结果偏离官方 `q5.out` |
| 各后端输入格式不同 | 正式后端统一 Arrow IPC | 降低文本解析口径差异 |
| mapped 被称为“无传输” | 改成“无显式大块 H2D、仍经 PCIe 远程读” | C005 |
| resident 尚未实现 | 工具返回明确 unsupported | 防止用 cold 冒充 resident |
| hybrid 有并发时段 | 只报告 duration overlap | 没有 Nsight kernel timeline |
| hybrid 没有加速 | 保留负结果 | 最佳 222.832 ms，CPU 61.414 ms |

## 未解决问题

当前 CPU 线程扩展很早变平，可能受计划准备、NUMA 和内存带宽影响，但没有单独
实验把这些因素拆开。
