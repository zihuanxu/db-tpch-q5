# V5 Formal SF1 Evidence

This directory is the frozen V5 formal experiment bundle for TPC-H Q5.

## Protocol

- Dataset: canonical Arrow SF1 at `data/tpch_sf1_arrow`.
- Query: region `ASIA`, date range starting `1994-01-01`.
- Matrix: 19 exact configurations from `experiments/v5_formal_sf1.yml`.
- Samples: 3 warmups and 10 measured cold-process runs per configuration.
- Oracle hash: `542abf4003633c7c`.
- Result: 190/190 measured and 57/57 warmup runs succeeded.

`query_total_ms` is backend-internal query time. `process_elapsed_ms` additionally
contains process startup, Arrow loading/checksums, and Python/Conda startup where
applicable. cuDF reports Arrow-to-cuDF preparation separately as `load_ms` and
does not include it in `query_total_ms`.

## Main Observations

| Configuration | Median query ms | Median process ms |
| --- | ---: | ---: |
| specialized CPU, 1 thread | 86.893 | 502.736 |
| specialized CPU, 16 threads | 61.414 | 381.285 |
| Arrow Acero, 32 threads | 321.535 | 707.231 |
| cuDF | 116.427 | 3682.381 |
| gpu-copy | 314.151 | 1008.970 |
| gpu-managed | 358.158 | 1006.683 |
| gpu-mapped | 412.264 | 1134.574 |
| hybrid, CPU ratio 0.25 | 295.435 | 905.699 |
| hybrid, CPU ratio 0.50 | 254.478 | 887.749 |
| hybrid, CPU ratio 0.75 | 222.832 | 888.370 |

The current hybrid implementation is correct and concurrent but is not faster
than the specialized CPU backend at SF1. CPU and GPU independently build their
plans, and the GPU side stages Arrow columns on every run. This is a negative
performance result and should not be presented as a hybrid speedup.

## Files

- `raw.csv`: 190 measured schema-version 1 records.
- `warmups.csv`: 57 retained warmup records.
- `summary.csv`: statistics recomputed from `raw.csv`.
- `commands.txt`: every backend command in execution order.
- `logs/`: one stdout and stderr file per process.
- `environment.json`: CPU, OS, CUDA, GPU, compiler, and Python capture.
- `correctness.json`: result and coverage gate generated by finalize.
- `matrix.yml`: exact matrix copied into the bundle by finalize.
- `manifest.json` and `manifest.sha256`: artifact hashes and bundle metadata.
