# 七步接管路线

时间紧时按顺序读，每课最后先练“一分钟复述”。建议学习顺序：

1. Q5 到底在算什么；
2. Arrow 数据如何放；
3. CPU 物理计划为什么快；
4. CUDA 三种内存模式；
5. CPU--GPU 混合怎么切数据；
6. 实验数字应该怎样解释；
7. 怎样向老师诚实说明结果和不足。

长篇背景仍保留在 `docs/PROJECT_HANDOVER_GUIDE.md`。当前正式数字以
`docs/artifacts/v7_sf1_resident`、`v7_sf10_resident`、`v7_hybrid_model`、
`v7_profiler` 和 `docs/research/CLAIM_LEDGER.md` 为准。V5 只用于解释 cold 与
resident 为什么会得出不同排名。
